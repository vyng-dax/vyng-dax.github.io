# Data Analyst Portfolio Website

A responsive pastel-pink portfolio template built with plain HTML and CSS. No framework or build step is required.

## Preview locally on a Mac
1. Unzip the downloaded folder.
2. Open `index.html` in Chrome or Safari.
3. Edit `index.html` with a text editor such as VS Code, CotEditor, or TextEdit in plain-text mode.
4. Edit `style.css` to change colors, spacing, and typography.

## Personalize before publishing
Search `index.html` for:
- `Your Name` — replace with your name.
- `your.email@example.com` — replace with your professional email.
- `https://www.linkedin.com/` and `https://github.com/` — replace with your profile URLs.
- Project placeholders — replace with completed project descriptions, verified findings, and links.
- Resume placeholder — after adding `resume.pdf` to this folder, change the resume button to `<a class="button button-primary button-small" href="resume.pdf" target="_blank" rel="noreferrer">View my resume ↗</a>`.

The project cards are examples/placeholders, not claims of completed work. Only publish skills and findings you can explain honestly.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload `index.html`, `style.css`, and any files you want to publish (such as `resume.pdf`) to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait a few minutes. Your site should appear at `https://yourusername.github.io/`.

Do not upload private information or sensitive documents. Review your resume PDF before publishing it publicly.
