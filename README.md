# Vy Nguyen Portfolio Website

A responsive portfolio site built with plain HTML and CSS. No framework or build step is required.

The homepage (`index.html`) is the general portfolio hub. Event planning work lives on `events.html`. Social Media Office lives on `social-media-office.html`.

## Preview locally
1. Open `index.html` in a browser, or serve the folder with a local static server.
2. Edit `index.html`, `events.html`, `social-media-office.html`, and `style.css` as needed.

## Publish with GitHub Pages
The site is published from the `main` branch of `vyng-dax/vyng-dax.github.io` to https://vyng-dax.github.io/.

Do not upload private information or sensitive documents.
